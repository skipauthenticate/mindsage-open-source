# Code of Conduct

MindSage contributors are expected to keep project spaces useful, direct, and respectful.

## Expected Behavior

- Discuss ideas and code on their merits.
- Assume private data and security reports are sensitive.
- Be specific when raising concerns and generous when clarifying intent.
- Welcome contributors across experience levels while keeping quality standards clear.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory conduct.
- Publishing private information, credentials, security reports, or user data.
- Deliberately disrupting issues, pull requests, or maintainer workflows.

## Enforcement

Maintainers may edit or remove inappropriate content, close discussions, restrict participation, or escalate to the hosting platform when needed. Security-sensitive disclosures should follow `SECURITY.md`.
